# Модуль фильтрации безразмерных кривых

Модуль реализует физически корректную фильтрацию и унифицированную интерполяцию для безразмерных кривых pD(Y) согласно контракту и рекомендациям статьи.

## Структура модуля

```
filtration/
├── __init__.py              # Экспорт основных классов
├── filters.py               # SignalFilters - методы фильтрации
├── physics.py               # PhysicsConstraints - физические ограничения
├── denoise.py               # MLDenoiser - опциональный ML-денойзинг
├── unified_interpolator.py  # UnifiedInterpolator - главный класс
└── utils.py                 # Вспомогательные функции
```

## Основные компоненты

### 1. SignalFilters
Реализует методы фильтрации:
- `savgol()` - Фильтр Савицкого-Голея
- `gaussian()` - Гауссовское сглаживание
- `kalman()` - Фильтр Калмана для нестационарного шума
- `log_domain()` - Фильтрация в логарифмическом масштабе
- `hybrid()` - Гибридный фильтр (по умолчанию)
- `denoise()` - Универсальный метод с автоматическим выбором

### 2. PhysicsConstraints
Применяет физические ограничения:
- `monotonic()` - Восстановление монотонности
- `limit_curvature()` - Ограничение второй производной
- `remove_oscillations()` - Удаление осцилляций
- `asymptotic_fix()` - Исправление асимптотик
- `enforce_all()` - Применение всех ограничений

### 3. UnifiedInterpolator
Главный класс, объединяющий всё:
- Автоматический выбор метода фильтрации
- Применение физических ограничений
- Построение единой модели интерполяции (GP/RBF/Spline)
- Поддержка batch-режима для банка шаблонов

## Пример использования

```python
from helpers.dimensionless.filtration import UnifiedInterpolator
import numpy as np

# Создаём интерполятор
interpolator = UnifiedInterpolator(
    filter_method=None,  # Автоматический выбор
    use_ml_denoise=False,  # Опционально
    enforce_physics=True,
    interpolation_method='gp'  # 'gp', 'rbf', или 'spline'
)

# Обучение на данных
Y = np.array([...])  # Безразмерная ось
pD = np.array([...])  # Значения pD(Y)

interpolator.fit(Y, pD, params={'skin': 0.5, 'N': 10, 'a_L': 0.1})

# Предсказание для новых точек
Y_new = np.array([...])
pD_pred = interpolator.predict(Y_new)
```

## Требования

## Особенности реализации

1. **Автоматический выбор фильтра**: На основе SNR, дисперсии производной и оценки осцилляций
2. **Логарифмическая фильтрация**: Автоматически применяется, если данные изменяются более чем на порядок
3. **Физические ограничения**: Всегда применяются после фильтрации для обеспечения корректности
4. **Обработка пропусков**: Автоматическое заполнение NaN значений
5. **Batch-режим**: Поддержка обработки нескольких кривых одновременно
