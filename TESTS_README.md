# Комплексные тесты для интерполяции безразмерных кривых и GUI

## Обзор

Этот документ описывает комплексные тесты для системы интерполяции безразмерных кривых и нагрузочные тесты для GUI приложения.

## Структура тестов

### 1. Тесты интерполяции (`tests/test_dimensionless_interpolation_comprehensive.py`)

#### Тесты на объёмных синтетических данных

- **`test_fit_large_dataset`**: Обучение интерполятора на 20 скважинах с 500 точками каждая
- **`test_predict_large_dataset`**: Предсказание на большом наборе данных
- **`test_interpolation_accuracy`**: Проверка точности интерполяции (RMSE)
- **`test_stability_check_on_large_dataset`**: Проверка стабильности интерполяции

#### Тесты на реальных данных

- **`test_interpolation_on_test_csv`**: Интерполяция на данных из `test.csv`
- **`test_interpolation_on_test_bad_csv`**: Интерполяция на проблемных данных из `test_bad.csv` (создается автоматически)
  - Пропуски в данных
  - Выбросы
  - Проверка устойчивости к проблемным данным

#### Тесты взаимодействия между модулями

- **`test_integration_dimensionless_analysis_interpolating`**: Интеграция `dimensionless_analysis` и `dimensionless_interpolating`
- **`test_integration_parse_interpolate_plot`**: Полный цикл парсинг -> конвертация -> интерполяция -> использование

#### Тесты поидемпотентности

- **`test_interpolation_idempotency`**: Результат не меняется при повторном вызове с теми же данными
- **`test_interpolation_idempotency_on_already_interpolated`**: Интерполяция уже интерполированных данных не меняет результат

### 2. Нагрузочные тесты GUI (`tests/test_gui_load.py`)

#### Тесты для кнопки "Построить график"

- **`test_1000_clicks_plot_button_stability`**: 1000 кликов - программа не должна ломаться
  - Проверка отсутствия исключений
  - Проверка стабильности виджета графика
  - Измерение времени выполнения
  
- **`test_rapid_plot_clicks_no_hang`**: Быстрые клики (50 за раз) не должны вызывать зависание
  - Проверка отзывчивости (< 100 мс на обработку событий)
  
- **`test_plot_button_memory_usage`**: Проверка использования памяти при многократных кликах
  - Измерение роста памяти
  - Проверка, что рост < 100 МБ

#### Тесты для интерполяции

- **`test_100_clicks_interpolation_no_hang`**: 100 кликов по интерполяции - программа не должна виснуть
  - Проверка отсутствия зависаний (каждая операция < 5 с)
  - Проверка отзывчивости между операциями
  
- **`test_interpolation_idempotency`**: Идемпотентность интерполяции в GUI
  - Проверка, что повторная интерполяция дает тот же результат
  
- **`test_interpolation_on_already_interpolated_data`**: Интерполяция уже интерполированных данных не меняет результат

#### Тесты производительности

- **`test_plot_creation_performance`**: Производительность создания графика
  - Среднее время < 500 мс
  - Максимальное время < 1 с
  
- **`test_interpolation_performance`**: Производительность интерполяции
  - Среднее время < 2 с
  - Максимальное время < 5 с

## Запуск тестов

### Все тесты

```bash
pytest tests/test_dimensionless_interpolation_comprehensive.py tests/test_gui_load.py -v
```

### Только быстрые тесты (без нагрузочных)

```bash
pytest tests/test_dimensionless_interpolation_comprehensive.py tests/test_gui_load.py -v -m "not slow"
```

### Только нагрузочные тесты

```bash
pytest tests/test_gui_load.py -v -m slow
```

### Тесты на реальных данных

```bash
pytest tests/test_dimensionless_interpolation_comprehensive.py::TestRealDataFiles -v
```

### Тесты идемпотентности

```bash
pytest tests/test_dimensionless_interpolation_comprehensive.py::TestIdempotency tests/test_gui_load.py::TestGUILoadInterpolation::test_interpolation_idempotency -v
```

## Требования

- pytest >= 8.3.3
- PySide6 для GUI тестов
- numpy, pandas, scipy, scikit-learn для тестов интерполяции

## Примечания

1. **test_bad.csv**: Создается автоматически при запуске тестов и содержит проблемные данные (пропуски, выбросы)

2. **Нагрузочные тесты помечены `@pytest.mark.slow`**: Запускайте их отдельно, так как они могут занимать значительное время

3. **GUI тесты требуют QApplication**: Они автоматически создают QApplication в фикстурах

4. **Измерение памяти**: Используется `tracemalloc` для отслеживания утечек памяти в GUI тестах

## Ожидаемые результаты

### Тесты интерполяции

- Все методы интерполяции должны работать стабильно
- RMSE должен быть < 1.0 для обучающих данных
- Стабильность проверяется методом `check_stability`
- Идемпотентность обеспечивает, что повторные вызовы дают одинаковый результат

### Нагрузочные тесты GUI

- 1000 кликов по графику: выполнение за разумное время, без исключений
- 100 кликов по интерполяции: без зависаний, отзывчивость < 1 с между операциями
- Память: рост < 100 МБ при 100 кликах
- Производительность: график < 500 мс, интерполяция < 2 с в среднем

## Отчетность

Тесты выводят подробную информацию о:
- Времени выполнения
- Использовании памяти
- Найденных проблемах (зависания, исключения)
- Метриках производительности
