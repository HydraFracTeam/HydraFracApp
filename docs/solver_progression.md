## Введение

В приложении **HydraFracApp** реализован гибридный алгоритм решения обратной задачи гидродинамических исследований скважин (ГДИС) после многостадийного гидравлического разрыва пласта (МГРП). Прогрессия (подбор) основных параметров:

- **k** — проницаемость пласта (мД)
- **s** (или S) — скин-фактор (безразмерный)
- **L** — полудлина трещины (м)

осуществляется через **многоэтапный конвейерный процесс** с последовательным сужением пространства поиска.

## Безразмерные параметры X и Y

Перед началом прогрессии параметров входные данные (давление P(t) и дебит Q(t)) преобразуются в безразмерные параметры, которые используются для сравнения с эталонными кривыми из библиотеки.

### Фильтрационный параметр X

Безразмерный фильтрационный параметр вычисляется по формуле:

```
X = (0.00864 × k × h × |ΔP|) / (μ × B × Q)
```

где:
- `k` — проницаемость пласта, мД
- `h` — эффективная толщина пласта, м
- `ΔP` — депрессия (разность пластового и забойного давлений), атм
- `μ` — вязкость флюида, сПз
- `B` — объёмный коэффициент нефти, м³/м³
- `Q` — дебит (нормированный на число трещин), м³/сут

**Ключевое свойство**: `X ∝ k` — параметр X линейно пропорционален проницаемости k при фиксированных остальных параметрах.

### Ёмкостной параметр Y

Безразмерный ёмкостной параметр вычисляется по формуле:

```
Y = (Q × B × t) / (24 × φ × Ct × h × |ΔP| × L²)
```

где:
- `Q` — дебит на одну трещину, м³/сут
- `B` — объёмный коэффициент нефти, м³/м³
- `t` — время, сут
- `φ` — пористость, доли единицы
- `Ct` — общая сжимаемость системы, 1/атм
- `h` — толщина пласта, м
- `ΔP` — депрессия, атм
- `L` — полудлина трещины, м

**Ключевое свойство**: `Y ∝ 1/L²` — параметр Y обратно пропорционален квадрату полудлины трещины.

## Этапы прогрессии параметров

Алгоритм последовательно сужает пространство поиска, переходя от дискретных параметров (skin, N) к непрерывным (L, k). Каждый этап использует результаты предыдущего для повышения точности подбора.

```
Входные данные (X, Y)
        ↓
[Этап 0] Подготовка — интерполяция на логарифмическую сетку
        ↓
[Этап 1] Beam Search → выбор Skin-фактора (top-k)
        ↓
[Этап 2] Перебор N → выбор количества трещин
        ↓
[Этап 3] Beam Search → выбор a/L
        ↓
[Этап 4] Перебор L → выбор полудлины трещины
        ↓
[Этап 5] Восстановление k → расчёт проницаемости
        ↓
Результат: {skin, N, L, a/L, k, misfit}
```

### Этап 1: Выбор Skin-фактора (s)

**Назначение**: Определение оптимального значения скин-фактора, характеризующего степень загрязнения или стимуляции призабойной зоны.

**Метод**: Beam Search (поиск луча)

**Реализация** ([`solver/solver_new.py:305`](solver/solver_new.py:305)):

```python
def select_skin(self, samples, h_known=None, beam=5):
    """
    Выбор лучшего skin-фактора методом beam search.
    
    Алгоритм:
    1. Для каждого skin из библиотеки вычисляется невязка формы
    2. Применяется весовой коэффициент по толщине пласта
    3. Отбираются top-k лучших значений
    """
    skin_scores = {}
    skin_scales = {}
    
    for s in samples:
        skin = s["skin"]
        F, sx, sy = self._sample_misfit(s)  # вычисление невязки
        F_w = F / _h_weight(s["h"], h_known)  # вес по толщине
        if skin not in skin_scores or F_w < skin_scores[skin]:
            skin_scores[skin] = F_w
            skin_scales[skin] = (sx, sy)
    
    top_skins = select_top_k(skin_scores, beam)
    return top_skins, skin_scores
```

**Весовой коэффициент по толщине** ([`_h_weight()`](solver/solver_new.py:58)):

```python
def _h_weight(h_sample, h_known):
    """
    Мягкий весовой коэффициент по близости h.
    weight = 1 / (1 + |Δh| / h_known), допуск ±50%.
    """
    if h_known is None or h_known <= 0:
        return 1.0
    return 1.0 / (1.0 + abs(h_sample - h_known) / h_known)
```

**Особенности**:
- Используется функция невязки формы `misfit_shape` с **нормировкой** по медиане Y
- Нормировка убирает влияние вертикального масштаба (проницаемости k), сохраняя только форму кривой
- Beam width (по умолчанию 5) определяет количество кандидатов для следующего этапа

### Этап 2: Выбор количества трещин (N)

**Назначение**: Определение оптимального количества трещин горизонтального ствола.

**Метод**: Полный перебор всех комбинаций

**Реализация** ([`solver/solver_new.py:331`](solver/solver_new.py:331)):

```python
def select_N(self, samples, top_skins, beam=5):
    """
    Выбор лучшего N для каждого skin.
    
    Алгоритм:
    1. Фильтрация samples по top-skins
    2. Перебор всех N для каждого skin
    3. Выбор лучшей пары (skin, N)
    """
    relevant = [s for s in samples if s["skin"] in top_skins]
    sn_scores = {}
    sn_scales = {}
    
    for s in relevant:
        key = (s["skin"], s["N"])
        F, sx, sy = self._sample_misfit(s)
        if key not in sn_scores or F < sn_scores[key]:
            sn_scores[key] = F
            sn_scales[key] = (sx, sy)
    
    best_key = min(sn_scores, key=sn_scores.get)
    best_skin, best_N = best_key
    return best_skin, best_N, sn_scores
```

**Особенности**:
- Если `N_fixed` задан — используется фиксированное значение
- Иначе — полный перебор всех N для каждого skin
- Возвращается лучшая пара `(skin, N)` по минимальной невязке

### Этап 3: Выбор параметра a/L

**Назначение**: Определение отношения расстояния до границы пласта к длине трещины (параметр, характеризующий взаимодействие трещин с границами).

**Метод**: Beam Search

**Реализация** ([`solver/solver_new.py:352`](solver/solver_new.py:352)):

```python
def select_aL(self, samples, skin, N, beam=5):
    """
    Выбор лучшего a/L для заданных skin и N.
    """
    relevant = [s for s in samples
                if s["skin"] == skin and s["N"] == N]
    al_scores = {}
    
    for s in relevant:
        al = s["a/L"]
        F, _, _ = self._sample_misfit(s)
        if al not in al_scores or F < al_scores[al]:
            al_scores[al] = F
    
    top_aL = select_top_k(al_scores, beam)
    return top_aL, al_scores
```

**Особенности**:
- `a/L` — безразмерный параметр (отношение)
- Влияет на форму безразмерной кривой в позднем режиме
- Отбираются top-k значений для интерполяции на следующем этапе

### Этап 4: Выбор полудлины трещины (L)

**Назначение**: Определение оптимальной полудлины трещины гидравлического разрыва.

**Метод**: Перебор + интерполяция/смешивание кривых

**Реализация** ([`solver/solver_new.py:373`](solver/solver_new.py:373)):

    """

    Алгоритм:
    1. Группировка кривых по значениям L
    2. Для каждого L выбирается лучшая кривая
    3. Если лучшее L на границе — интерполяция с соседями

#### Механизм смешивания кривых

При недостаточном перекрытии диапазонов X между фактической и эталонной кривыми применяется интерполяция:

**Функция смешивания** ([`_blend_curves()`](solver/solver_new.py:25)):

```python
def _blend_curves(y1, y2, alpha):
    """
    Линейная смесь двух кривых: alpha=0 → y1, alpha=1 → y2.
    nan-точки одной кривой заполняются из другой.
    """
    out = (1.0 - alpha) * y1 + alpha * y2
    out = np.where(np.isnan(y1), y2, out)
    out = np.where(np.isnan(y2), y1, out)
    return out
```

**Выбор коэффициента смешивания** ([`_choose_alpha()`](solver/solver_new.py:36)):

```python
def _choose_alpha(f1, f2):
    """
    Коэффициент смешивания по относительной разности ошибок:
      < 30%  → берём ближайшую (0 или 1)
      30-40% → линейная интерполяция
      > 40%  → середина (0.5)
    """
    if not (np.isfinite(f1) and np.isfinite(f2)):
        return 0.0 if np.isfinite(f1) else 1.0
    denom = max(f1, f2)
    if denom == 0:
        return 0.0
    rel = abs(f1 - f2) / denom
    if rel < 0.30:
        return 0.0 if f1 <= f2 else 1.0
    elif rel > 0.40:
        return 0.5
    else:
        t = (rel - 0.30) / 0.10
        return t * 0.5
```

### Этап 5: Восстановление проницаемости (k)

**Назначение**: Расчёт абсолютного значения проницаемости на основе масштабных коэффициентов, полученных при выравнивании кривых.

**Метод**: Восстановление из масштаба

**Реализация** ([`solver/solver_new.py:510`](solver/solver_new.py:510)):

```python
def recover_k(self, best_sample, k_ref=5.0, k_bounds=(1e-5, 100)):
    """
    Восстановление проницаемости из масштабных коэффициентов.
    
    Соотношение: X ∝ k при фиксированных статических параметрах
    →  X_fact / X_ref = k_real / k_ref
    →  k_real = k_ref * median(X_fact) / median(X_ref)
    """
    x_fact = self._x_fact_raw
    x_ref = best_sample["dynamic"]["X"].values
    
    # Фильтрация положительных значений
    mask_fact = x_fact > 0
    mask_ref = x_ref > 0
    
    med_fact = np.median(x_fact[mask_fact])
    med_ref = np.median(x_ref[mask_ref])
    
    if med_ref <= 0:
        return None
    
    k_real = k_ref * (med_fact / med_ref)
    k_real = float(np.clip(k_real, k_bounds[0], k_bounds[1]))
    
    return k_real
```

**Физическое обоснование**:
- Параметр X линейно пропорционален проницаемости k (см. формулу выше)
- Отношение медиан X_fact / X_ref равно отношению проницаемостей
- Референсное значение k_ref = 5.0 мД используется как базовое из библиотеки

## Механизмы оптимизации

### Beam Search (Поиск луча)

Метод отбора лучших кандидатов на каждом этапе:

```python
def select_top_k(scores: Dict, k: int) -> List:
    """
    Выбор top-k лучших элементов из словаря по значениям.
    Сортировка по возрастанию ошибки.
    """
    items = sorted(scores.items(), key=lambda x: x[1])
    return [key for key, value in items[:k]]
```

**Параметры**:
- `beam=5` — количество лучших кандидатов для следующего этапа
- Уменьшает вычислительную сложность без потери точности

## Детальные алгоритмы

### Общий алгоритм решения (solve)

```python
def solve(self, x_fact, y_fact,
          W_fixed=None, N_fixed=None, h_known=None,
          k_bounds=(1e-5, 10), xf_bounds=(1e-3, 100),
          beam=5):
    """
    Полный ступенчатый подбор параметров.
    
    Последовательность:
    1. Подготовка входной кривой (интерполяция на лог-сетку)
    2. Фильтрация библиотеки по W и N
    3. Этап 1: Выбор Skin
    4. Этап 2: Выбор N (или фиксация)
    5. Этап 3: Выбор a/L
    6. Этап 4: Выбор L с интерполяцией
    7. Этап 5: Восстановление k
    """
    # Подготовка
    self._prepare(x_fact, y_fact)
    samples = self._filter_library(W_fixed, N_fixed)
    
    # Этап 1: Skin
    top_skins, _ = self.select_skin(samples, h_known=h_known, beam=beam)
    
    # Этап 2: N
    if N_fixed is not None:
        best_skin, best_N = top_skins[0], N_fixed
    else:
        best_skin, best_N, _ = self.select_N(samples, top_skins, beam=beam)
    
    # Этап 3: a/L
    top_aL, _ = self.select_aL(samples, best_skin, best_N, beam=beam)
    
    # Этап 4: L
    best_L, best_aL, x_ref_f, y_ref_f, _, _, misfit_f = self.select_L(
        samples, best_skin, best_N, top_aL
    )
    
    # Этап 5: k
    k_opt = self.recover_k(best_sample_for_k, k_ref=5.0, k_bounds=k_bounds)
    
    return {
        "skin": best_skin,
        "N": best_N,
        "L": best_L,
        "aL": best_aL,
        "h": best_h,
        "W": best_W,
        "params": {"k": k_opt, "xf": best_L},
        "misfit": misfit_f,

    }
```

## Заключение

Механизм прогрессии параметров **k, s, L** в HydraFracApp представляет собой **иерархический многоступенчатый алгоритм**, который:

1. **Последовательно сужает пространство поиска** — от дискретных параметров (s, N) к непрерывным (L, k)

2. **Использует разные функции невязки** — с нормировкой для выбора формы, без нормировки для финальной оптимизации

3. **Применяет интерполяцию** — для непрерывности результатов между дискретными значениями L
