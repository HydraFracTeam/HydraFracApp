# Индекс документации

Этот раздел содержит полную документацию проекта согласно техническому заданию.

## Структура документации

### Основные документы

- **[README.md](README.md)** - Мастер-документ с описанием проекта, архитектуры и критериев успеха

### Диаграммы (PNG)

Все диаграммы находятся в папке `diagrams/` и отображают архитектуру и процессы системы.

- **[components_global.png](diagrams/components_global.png)** - Диаграмма компонентов системы
  - Показывает основные модули: GUI, GraphCore, MLCore, AnalysisCore, DataCore, ConfigCore
  - Отображает интерфейсы взаимодействия между компонентами

- **[pack-class_global.png](diagrams/pack-class_global.png)** - Диаграмма пакетов проекта
  - Группировка классов по функциональным пакетам
  - Зависимости между пакетами

- **[activities_user.png](diagrams/activities_user.png)** - Диаграмма активности: построение графика безразмерных кривых
  - Полный поток выполнения метода `on_plot_dimensionless_selected()`
  - Входные параметры, валидация, основные шаги, обработка ошибок

- **[act_interpol.png](diagrams/act_interpol.png)** - Диаграмма активности: интерполяция данных
  - Поток выполнения метода интерполяции
  - Выбор метода, обучение модели, оценка качества

- **[act_flow_regime.png](diagrams/act_flow_regime.png)** - Диаграмма активности: анализ режима течения
  - Вычисление производных, определение режима, оценка уверенности

- **[activities_load.png](diagrams/activities_load.png)** - Диаграмма активности: загрузка данных
  - Парсинг файлов, валидация, создание объектов данных

- **[seq_user_global.png](diagrams/seq_user_global.png)** - Диаграмма последовательностей пользовательского сценария
  - Полный пользовательский сценарий от старта до экспорта отчета
  - Взаимодействие между компонентами в процессе работы

### Тестирование

- **[tests_table.md](tests_table.md)** - Полная таблица всех тестов проекта
  - Описание каждого теста
  - Команды запуска
  - Классификация по тяжести (легкий/средний/тяжелый/очень тяжелый)

## Использование диаграмм

Все диаграммы доступны в формате PNG в папке `diagrams/`. Они могут быть открыты в любом просмотрщике изображений или встроены в документацию.

## Обновление документации

При изменении архитектуры проекта необходимо обновить соответствующие документы:

1. **Диаграммы** - при изменении структуры или процессов
2. **README.md** - при изменении архитектуры или функциональности
3. **Таблица тестов** - при добавлении новых тестов
4. **DOCUMENTATION_STATUS.md** - при изменении статуса документов
