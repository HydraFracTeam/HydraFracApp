# HydraFracApp — Руководство пользователя

> Версия: 1.0 | Дата: июнь 2026

---

## 1. Назначение программы

**HydraFracApp** — десктопное приложение для интерпретации кривых стабилизации давления (КСД) многотрещинных горизонтальных скважин после многостадийного гидравлического разрыва пласта (МГРП).

Программа автоматически определяет три ключевых параметра пласта и трещины:

| Параметр | Обозначение | Единица измерения |
|---|---|---|
| Скин-фактор | S | безразмерный |
| Проницаемость | k | мД |
| Полудлина трещины | L | м |

Подбор выполняется путём сопоставления фактических замеров давления с библиотекой эталонных безразмерных кривых.

---

## 2. Запуск приложения

Убедитесь, что все зависимости установлены (файл `requirements.txt`):

```bash
pip install -r requirements.txt
```

Запуск:

```bash
python main.py
```

Приложение использует базу данных эталонных кривых (`storage/db/reference_curves.db`), которая идёт в комплекте.

### Элементы управления

**Левая панель (ввод данных):**

| Блок | Элементы |

| **Загрузка** | Кнопки: «Загрузить файл», «Вставить из буфера», «Сброс»; импорт/экспорт сессии (.fflow) |
| **Статические параметры** | Spinbox'ы: W, h, μ, φ, B, ct, P0; выпадающий список N; поле Q (если нет дебита в файле); кнопка «Ввести статические параметры» |

- ☑ Производная Бурде

- Downsample threshold (порог прореживания)
- Downsample points per decade (точки на декаду)
- Overlap percentage (процент перекрытия)

## 4. Пошаговая инструкция работы

Работа с программой проходит строго по этапам: каждый следующий блок разблокируется только после завершения предыдущего.

```
Загрузка данных → Статические параметры → Границы оптимизации → Расчёт
```

### 4.1. Шаг 1 — Загрузка динамических данных

**Источники данных:**

1. **Файл CSV/LAS** — кнопка «Загрузить файл»
   - Обязательные столбцы: `t` (время, часы), `P` (давление, кгс/см²)
   - Опционально: `Q` (суммарный дебит, м³/сут)
   - Минимальное количество точек: 20
   - Время должно идти монотонно (без возвратов назад)

2. **Буфер обмена** — кнопка «Вставить из буфера»
   - Открывается диалог вставки текстовых данных
   - Формат: колонки t, P, Q (Q опционально), разделитель — табуляция или запятая

**Автосплиттер КСД/КВД:**

После загрузки программа автоматически определяет участки. Появляется диалог с выбором режима:

| Режим | Описание |
|---|---|
| **КСД** | Оставить только кривую стабилизации давления |
| **КВД** | Оставить только кривую восстановления давления |
| **Оба режима** | Оставить оба участка (с предупреждением) |
| **Игнорировать** | Использовать все данные без разделения |

На графике давления отображается вертикальная линия разделения.

После успешной загрузки разблокируется блок **«Статические параметры»**.

---

### 4.2. Шаг 2 — Ввод статических параметров пласта

Заполните все поля:

| Поле | Описание | Ед. изм. |
|---|---|---|
| W | Длина горизонтального ствола | м |
| h | Эффективная толщина пласта | м |
| μ (mu) | Вязкость флюида | сПз |
| φ (phi) | Пористость | доли ед. |
| B (Bo) | Объёмный коэффициент нефти | м³/м³ |
| ct | Общая сжимаемость системы | 1/атм |
| N | Количество трещин (выбор из списка) | шт. |
| P0 | Пластовое давление | кгс/см² |

**Важно:** P0 должно быть больше максимального значения давления в загруженном ряду.

Если дебит отсутствовал в исходном файле, появится дополнительное поле **Q_constant** — введите постоянное значение дебита (м³/сут). Оно будет использовано для всех точек замера.

Нажмите кнопку **«Ввести статические параметры»**. После успешной валидации будет выполнен расчёт депрессии, нормировка дебита на N, производной Бурде. Разблокируется блок **«Границы оптимизации»**.

---

### 4.3. Шаг 3 — Ввод границ оптимизации

Укажите диапазоны поиска:

| Поле | Описание |
|---|---|
| L_min | Минимальная полудлина трещины (м) |
| L_max | Максимальная полудлина трещины (м) |
| k_min | Минимальная проницаемость (мД) |
| k_max | Максимальная проницаемость (мД) |

Требования:
- max ≥ min для каждого параметра
- Все значения положительные

Нажмите кнопку **«Ввести границы оптимизации»**. Будут рассчитаны безразмерные параметры X и Y, построены графики. Разблокируется кнопка **«Рассчитать»**.

---

### 4.4. Шаг 4 — Предобработка данных (опционально)

Для улучшения качества подбора можно выполнить предобработку исходного сигнала давления. **Все операции применяются только к P(t)** — безразмерные X и Y пересчитываются автоматически после каждой операции.

| Кнопка | Что делает |
|---|---|
| **Интерполяция** | Восстанавливает пропуски давления (NaN) методом PCHIP; пропуски дебита заполняются последним известным значением (step-fill) |
| **Экстраполяция** | Продлевает временной ряд на ~50% точек: время — равномерным шагом, давление — лог-регрессионной моделью, дебит — константой |
| **Сглаживание** | Фильтр Савицкого–Голея с автоматическим подбором окна |
| **Выбросы** | Удаление аномальных точек по MAD (медианное абсолютное отклонение) с окном 7 и порогом 7 |
| **Сброс** | Полный возврат к исходным данным из файла |

**Механизм отката:** при ошибке любой операции исходные данные не изменяются — в отчёт выводится сообщение об ошибке.

---

### 4.5. Шаг 5 — Расчёт оптимальных параметров

Нажмите кнопку **«Рассчитать»**.

Процесс выполняется **асинхронно** — интерфейс не блокируется. В текстовом отчёте появится сообщение «Солвер запущен, идет расчет...».

После завершения:

1. Поля **S, k, L** заполняются найденными значениями лучшего решения
2. На графике **X-Y** отображаются:
   - **Фактическая кривая** (синим)
   - **Эталонная кривая** (красным/зелёным) — найденное соответствие
   - **Соседние кривые** (пунктиром) — кривые для Skin ±1, ±2 от найденного
3. Открывается **диалог сравнения решений**

#### Диалог сравнения

В диалоге представлен **список найденных решений**, отсортированных по возрастанию невязки (лучшие сверху):

| Параметр | Описание |
|---|---|
| S | Найденный скин-фактор |
| k | Найденная проницаемость (мД) |
| L | Найденная полудлина трещины (м) |
| Невязка | Значение функции misfit (чем меньше, тем лучше) |

Можно выбрать другое решение из списка — график эталонной кривой обновится.

## 5. Визуализация и графики

### График давления P(t)
- Основные точки — сплошной линией
- Интерполированные участки — маркерами/пунктиром
- Экстраполированные участки — другим стилем

### График дебита Q(t)
- Основные точки — сплошной линией
- Интерполированные/экстраполированные участки — маркерами

### График X-Y (безразмерные параметры)
- **X** (горизонтальная ось) — фильтрационный параметр
- **Y** (вертикальная ось) — ёмкостной параметр
- Отображаются фактические данные + эталон + семейство соседних кривых

### Производная Бурде (log-log)
- Диагностический график в двойном логарифмическом масштабе
- Используется для визуальной оценки режимов течения

**Управление графиками:**
- Чекбоксы над областью доков — показать/скрыть конкретный график
- Графики можно перетаскивать и перекомпоновывать внутри области
- Каждый график можно отделить в отдельное окно

## 7. Работа с сессиями (.fflow)

Сессия сохраняет **полное состояние** работы — все данные, настройки и результаты.

### Сохранение сессии
- Кнопка **«Экспорт сессии»** → выберите папку и имя файла (расширение .fflow)
- Сохраняется: исходные данные, обработанные данные, статические параметры, границы, результаты расчёта

### Загрузка сессии
- Кнопка **«Импорт сессии»** → выберите .fflow файл
- Восстанавливаются все графики, таблицы, поля ввода и результаты

**Переносимость:** файлы .fflock полностью переносимы между компьютерами и операционными системами.

---

## 8. Работа с несколькими сессиями

- Кнопка **«+»** на панели вкладок — открыть новую сессию
- Каждая вкладка — независимый сеанс работы со своими данными
- Вкладки можно закрывать (кроме последней)

## 9. Типичный сценарий работы

```
1. Открыть программу → python main.py
2. Загрузить CSV с замерами P(t), Q(t)
3. В диалоге автосплиттера выбрать "КСД"
4. Заполнить статические параметры (W, h, μ, φ, B, ct, N, P0)
5. Если Q не было в файле → ввести Q_constant
6. Задать диапазоны L [5..500] м, k [0.01..100] мД
7. Выполнить интерполяцию (если есть пропуски)
8. Выполнить сглаживание (если шумный сигнал)
9. Нажать "Рассчитать"
10. Просмотреть результаты в диалоге сравнения
11. При необходимости — сохранить сессию в .fflow
12. Экспортировать таблицы в CSV для отчёта
```

## 10. Возможные проблемы и пояснения

| Ситуация | Что делать |
|---|---|
| Не загружается файл | Проверьте формат: CSV или LAS; убедитесь, что есть столбцы t и P; минимум 20 точек |
| Ошибка «P0 должно быть больше P» | Увеличьте пластовое давление — оно должно превышать максимальное значение в ряду |
| Солвер не нашёл решения | Проверьте диапазоны L и k; проверьте длину скважины W и количество трещин N; попробуйте расширить границы |
| Графики пустые | Проверьте, включены ли чекбоксы отображения доков; переключитесь на вкладку «Графики» |
| Шумный сигнал давления | Используйте «Сглаживание», затем «Выбросы» |
| Хочу вернуть исходные данные | Нажмите «Сброс» в блоке предобработки или «Сброс» в блоке загрузки (сбросит всё) |
| Нужен другой Skin из списка | В диалоге сравнения выберите строку с нужным S — график и поля обновятся |

## 11. Горячие клавиши и особенности

- **Сброс всей сессии**: кнопка «Сброс» в блоке загрузки
- **Экспорт таблиц**: кнопки под таблицами на соответствующих вкладках
- **Скрытие/показ доков**: чекбоксы над областью графиков
- **Runtime-настройки**: кнопка ⚙ (шестерёнка) — для тонкой настройки отображения
