# Алгоритмы предобработки данных

Документация по реализованным алгоритмам предобработки данных в модуле `processing`.

## Сглаживание давления

Алгоритм: **Фильтр Савицкого-Голея (Savitzky-Golay)**

Файл: `smooth_pressure.py`

Описание:
- Используется для сглаживания шумов в данных давления
- Применяет локальный полиномиальный регрессионный анализ
- Сохраняет важные особенности формы сигнала
- Работает только с достоверными (не NaN) значениями
- Параметры:
  - `window_length`: размер окна сглаживания (нечетное число)
  - `polyorder`: степень локального полинома

Принцип работы:
1. Определяет достоверные значения давления
2. Применяет фильтр Савицкого-Голея к достоверным значениям
3. Заменяет исходные значения сглаженными данными

## Интерполяция давления

Алгоритм: **Интерполяция PCHIP (Piecewise Cubic Hermite Interpolating Polynomial)**

Файл: `interpolate_pressure.py`

Описание:
- Восстанавливает пропущенные значения давления
- Использует монотонную кубическую интерполяцию
- Сохраняет монотонность данных
- Не экстраполирует за пределы диапазона исходных данных

Принцип работы:
1. Находит достоверные (не NaN) точки давления
2. Строит PCHIP-интерполятор на основе временных и давлениевых данных
3. Вычисляет значения во всех точках временной сетки
4. Сохраняет маску интерполированных точек

## Интерполяция дебита

Алгоритм: **Метод продолжения тренда (forward-fill)**

Файл: `interpolate_debit.py`

Описание:
- Восстанавливает пропущенные значения дебита
- Использует метод "шаговой интерполяции" (step interpolation)
- Продолжает последнее известное значение до следующего достоверного значения

Принцип работы:
1. Находит первый достоверный элемент
2. Заполняет начальные пропуски этим значением
3. Проходит по всему массиву, заменяя NaN значениями последнего достоверного значения
4. Обновляет маску интерполированных точек

Пример:
```
[nan,100,nan,nan,80,nan,60,nan]
->
[100,100,100,80,80,60]
```

## Экстраполяция времени

Алгоритм: **Линейное продолжение временной сетки**

Файл: `extrapolate_time.py`

Описание:
- Продлевает временную сетку за пределы имеющихся данных
- Использует средний шаг между точками
- Параметр `extend_fraction` определяет долю новых точек (по умолчанию 0.5, т.е. 50%)

Принцип работы:
1. Вычисляет средний шаг времени на основе существующих данных
2. Добавляет новые точки с равномерным шагом
3. Формирует маску экстраполированных точек

## Экстраполяция давления

Алгоритм: **Полиномиальная экстраполяция в логарифмическом времени**

Файл: `extrapolate_pressure.py`

Описание:
- Продлевает давление за пределы имеющихся данных
- Использует полиномиальную модель в логарифмических координатах
- Автоматически выбирает оптимальную степень полинома
- Учитывает физическое ограничение: давление не должно возрастать

Принцип работы:
1. Преобразует время в логарифмический масштаб
2. Выбирает оптимальную степень полинома с помощью валидации
3. Обучает модель на последних 40% данных (хвостовая часть)
4. Прогнозирует значения для будущих точек
5. Применяет ограничение на возрастание давления

## Экстраполяция дебита

Алгоритм: **Продление последнего известного значения**

Файл: `extrapolate_debit.py`

Описание:
- Продлевает дебит за пределы имеющихся данных
- Использует постоянное значение (последнее известное)

Принцип работы:
1. Берет последнее достоверное значение дебита
2. Продлевает его на все новые временные точки
3. Формирует маску экстраполированных точек

## Удаление выбросов давления

Алгоритм: **Обнаружение выбросов по MAD (Median Absolute Deviation)**

Файл: `remove_pressure_outliers.py`

Описание:
- Обнаруживает и удаляет аномальные значения давления
- Использует скользящее окно и медиану
- Параметры:
  - `window`: размер скользящего окна (по умолчанию 7)
  - `threshold`: пороговое значение для определения выбросов (по умолчанию 7.0)

Принцип работы:
1. Для каждой точки вычисляет медиану и MAD в скользящем окне
2. Вычисляет нормализованное отклонение от медианы
3. Если отклонение превышает порог, точка считается выбросом
4. Заменяет выбросы на NaN значения
