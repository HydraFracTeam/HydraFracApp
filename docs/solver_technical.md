## Общее описание

Solver — модуль оптимизации для решения **обратной задачи интерпретации ГДИС** после МГРП.

**Цель:** определить параметры пласта и трещины:
- **S (Skin)** — скин-фактор
- **N** — количество трещин
- **k** — проницаемость, мД
- **L (xf)** — полудлина трещины, м

**Метод:** гибридный подход (Beam Search + Bayesian Optimization)

---

## Этапы оптимизации

### Этап 0: Подготовка входной кривой

Интерполирует входные данные на сетку (логарифмическую по умолчанию или переданную).

### Этап 1: Выбор Skin-фактора (Beam Search)

Перебор значений Skin из библиотеки, выбор top-k лучших.

### Этап 2: Выбор N

Для выбранных Skin перебор значений N, выбор лучшей комбинации.

### Этап 3: Байесовская оптимизация

Оптимизация непрерывных параметров k и xf:

```python
# Модификация эталонной кривой
y_mod = y_ref * k * (1 + 0.1 * log10(xf + 1))

# Сравнение с входными данными (БЕЗ нормализации!)
error = ensemble_misfit(x_ref, y_mod)
```

**Важно:** Нормализация НЕ используется — сравниваются реальные значения. 
Параметр k влияет на амплитуду кривой и напрямую отражается на ошибке.

## Функция невязки

### ensemble_misfit(x_ref, y_ref)

1. Интерполирует входную кривую на свою сетку
2. Интерполирует референс на сетку входной кривой
3. Сравнивает **raw значения** (без нормализации)
4. Вычисляет метрики по производным (linear, loglog)

---

## Метрики

- **L2**: Σ(y₁ - y₂)²
- **L1**: Σ|y₁ - y₂|
- **integral**: |∫y₁ - ∫y₂|
