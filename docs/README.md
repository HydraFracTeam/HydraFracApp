# Hydraulic Fracturing GUI - Анализ ГРП

Профессиональное приложение для анализа данных гидроразрыва пласта (ГРП) и разведки месторождений.

## Проект в целом

### Проблема и цель
Приложение решает проблему анализа месторождений нефти и газа, работая по месторождениям методом гидроразрыва пласта и фокусируясь на работе с безразмерными кривыми вне радиального режима.

**Основные задачи:**
- Анализ данных ГРП с использованием безразмерных параметров (X, Y)
- Визуализация безразмерных кривых в различных плоскостях отображения
- Интерполяция и экстраполяция данных с использованием ML-алгоритмов
- Определение режимов течения (билинейное, линейное, псевдорадиальное)
- Сопоставление с эталонными кривыми для оценки характеристик скважины

### Критерии успеха
**Метрики качества GUI:**
- Время отклика GUI < 500ms для всех операций (кроме загрузки файлов)
- Failure rate < 1% при многократных операциях (1000+ итераций)
- Линейный рост потребления памяти (R² > 0.8)
- Поддержка загрузки данных до 100K строк за < 5 секунд

**Метрики точности:**
- Точность ML-методов > 95% для интерполяции, фильтрации и обнаружения выбросов
- Физическая адекватность результатов (соответствие физическим законам ГРП)
- RMSE для интерполяции: отличное (< 0.01), хорошее (< 0.1)

**Метрики производительности:**
- Деградация производительности < 15% при длительной работе (10-20 минут)
- Стабильность при обработке больших объемов данных
- Эффективное использование памяти (без утечек)

**Сравнение с аналогами (Kappa Sapphire):**
- Сопоставимая или лучшая производительность интерполяции
- Расширенные возможности работы с безразмерными кривыми
- Специализация на нерадиальных режимах течения

### Ограничения

**Требования к времени отклика:**
- Операции построения графиков: < 500ms
- Операции интерполяции: < 2 секунды для средних данных
- Загрузка файлов: < 5 секунд на 100K строк
- Операции с диалогами: < 1000ms

**Требования к памяти:**
- Базовое потребление: < 200 MB
- Линейный рост при обработке данных (без экспоненциального роста)
- Отсутствие утечек памяти при длительной работе

**Требования к точности методов:**
- Интерполяция: RMSE < 0.1 для большинства случаев
- Фильтрация: улучшение корреляции с базовым сигналом
- Обнаружение выбросов: чувствительность > 80%, специфичность > 90%
- Физические ограничения: соблюдение законов сохранения и физических границ

## Архитектура

### Компоненты системы

**1. GUI (Графический интерфейс)**
- **Модуль**: `main.py`, `helpers/ui_setup.py`
- **Назначение**: Управление пользовательским интерфейсом, обработка событий, отображение результатов
- **Основные классы**: `MyApp` (главное окно приложения)
- **Функции**: Управление вкладками, обработка пользовательских действий, отображение графиков

**2. GraphCore (Методы отображения кривых/графиков)**
- **Модуль**: `helpers/dimensionless_plotting.py`
- **Назначение**: Построение графиков безразмерных кривых в различных плоскостях
- **Суть/обоснованность**: 
  - Группировка графиков по плоскостям отображения (X-pD, Y-pD, реальные параметры)
  - Использование PyQtGraph для интерактивной визуализации
  - Поддержка различных типов графиков: pD(X), dpD/dY(X), tD(Y), CD(X), X-Y график
  - Обработка данных из входных файлов и расчетных значений
- **Основные функции**: `plot_dimensionless_grouped()` - сгруппированное отображение графиков

**3. MLCore (Методы интерполяции с ML-алгоритмами)**
- **Модуль**: `helpers/ml_methods.py`, `helpers/dimensionless_interpolating.py`
- **Назначение**: Интерполяция и обработка данных с использованием машинного обучения
- **Методы**:
  - Random Forest интерполяция
  - Gaussian Process (GP) интерполяция
  - RBF (Радиальные базисные функции)
  - Физически ограниченная интерполяция
  - Адаптивная интерполяция (автоматический выбор метода)
- **Обоснованность**: 
  - ML-методы обеспечивают высокую точность для нелинейных зависимостей
  - Физически ограниченная интерполяция гарантирует соответствие физическим законам
  - Автоматический выбор метода оптимизирует баланс между точностью и скоростью

**4. AnalysisCore (Аналитическое ядро)**
- **Модуль**: `helpers/dimensionless_analysis.py`, `helpers/grp_analysis.py`, `helpers/physics.py`
- **Назначение**: Вычислительные методы анализа ГРП
- **Функциональность**:
  - Конвертация в безразмерные параметры (X, Y)
  - Анализ режимов течения
  - Вычисление индекса продуктивности
  - Определение переходов режимов
  - Физические расчеты (трансмиссивность, пористость, диффузивность)

**5. DataCore (Обработка данных)**
- **Модуль**: `helpers/parse_well_data.py`, `schemas/well_data.py`
- **Назначение**: Парсинг и валидация входных данных
- **Функциональность**:
  - Парсинг CSV/Parquet файлов
  - Валидация данных через Pydantic схемы
  - Группировка данных по скважинам
  - Извлечение параметров скважины (Skin, h, N, W, L, a/L)

**6. ConfigCore (Конфигурация)**
- **Модуль**: `config.py`
- **Назначение**: Централизованное хранение констант и настроек
- **Содержание**: Размеры окон, пороги качества, параметры по умолчанию

### Взаимодействие модулей

**Поток данных:**
1. **Загрузка данных**: `DataCore` → парсинг файла → создание объектов `WellTimeSeries`
2. **Отображение**: `GUI` → запрос данных → `GraphCore` → построение графиков
3. **Анализ**: `GUI` → выбор операции → `AnalysisCore` → вычисления → возврат результатов
4. **Интерполяция**: `GUI` → выбор метода → `MLCore` → обработка данных → `AnalysisCore` (конвертация в безразмерные) → возврат результатов
5. **Визуализация результатов**: `GUI` → получение данных → `GraphCore` → отображение

**Интерфейсы взаимодействия:**
- `GUI` ↔ `DataCore`: Загрузка данных через `parse_well_data()`
- `GUI` ↔ `GraphCore`: Построение графиков через `plot_dimensionless_grouped()`
- `GUI` ↔ `MLCore`: Интерполяция через `apply_ml_interpolation()`, фильтрация через `apply_ml_filter()`
- `GUI` ↔ `AnalysisCore`: Анализ через `convert_to_dimensionless_curves()`, `compute_flow_regime()`, `compute_productivity_index()`
- `MLCore` ↔ `AnalysisCore`: Использование безразмерных параметров для интерполяции

**Схема данных:**
- Входные данные: CSV/Parquet файлы → `WellTimeSeries` объекты
- Промежуточные данные: `DimensionlessParameters` (безразмерные параметры)
- Выходные данные: Графики, отчеты, экспортированные файлы

## Новые возможности

### Формат данных
Приложение работает с данными разведки месторождений в формате:
- **Skin** - фактор скин-эффекта
- **h** - толщина пласта (м)
- **N** - количество трещин
- **W** - ширина трещины (м)
- **L** - длина трещины (м)
- **a/L** - отношение a/L
- **ElemIdx** - индекс элемента
- **X, Y** - координаты (м) или безразмерные параметры из данных
- **t** - время (ч)
- **P** - давление (атм)
- **dP** - изменение давления (атм)
- **Q** - дебит (м³/сут)

### Профессиональный интерфейс

#### Вкладка "Безразмерные кривые"
- Построение графиков в различных плоскостях отображения
- Группировка графиков по типам (реальные параметры, безразмерные, типовые кривые, специальные пространства)
- Использование X и Y из данных или расчетных значений
- Опция отображения расчетных X и Y для сравнения

#### Вкладка "Анализ ГРП"
- Отображение параметров скважины
- Анализ режима течения
- Вычисление индекса продуктивности
- Обнаружение переходов режимов
- Автоматическая классификация:
  - Билинейное течение
  - Линейное течение
  - Псевдорадиальное течение

#### Вкладка "Эталонные кривые"
- Построение эталонных кривых для разных режимов
- Сопоставление с реальными данными
- Оценка качества сопоставления

#### Вкладка "Результаты"
- Сводка всех анализов
- Экспорт отчетов
- Сохранение результатов в текстовом формате

## Использование

1. Загрузите CSV/Parquet файл с данными в новом формате
2. Приложение автоматически распознает параметры скважины
3. Используйте вкладки для различных видов анализа
4. Выберите нужные графики через чекбоксы
5. Нажмите "Построить график" для отображения
6. Используйте "Очистить график" для сброса всех графиков
7. Экспортируйте результаты для дальнейшего использования
