# Объяснение системы фильтрации безразмерных кривых

## Общий процесс фильтрации

Система фильтрации предназначена для удаления шума из безразмерных кривых pD(Y), которые описывают поведение давления в скважине после гидроразрыва пласта (ГРП).

### Этапы обработки:

1. **Подготовка данных**: Удаление NaN значений, создание маски валидных точек
2. **Автоматический выбор метода**: Анализ характеристик сигнала (SNR, осцилляции, масштаб)
3. **Применение фильтра**: Сглаживание сигнала выбранным методом
4. **Физические ограничения**: Обеспечение физической корректности (монотонность, ограничение кривизны)
5. **Восстановление давления**: Преобразование отфильтрованного pD обратно в размерное давление

---

## Методы фильтрации

### 1. Фильтр Савицкого-Голея (Savitzky-Golay)

**Принцип работы:**
- Аппроксимирует локальные участки сигнала полиномом заданного порядка
- Вместо простого усреднения (как в скользящем среднем), сохраняет форму пиков и особенности сигнала
- Использует метод наименьших квадратов для подгонки полинома в скользящем окне

**Почему работает:**
```
Исходный сигнал: [y₁, y₂, y₃, ..., yₙ]
Для каждой точки i:
  1. Берём окно [yᵢ₋ₖ, ..., yᵢ, ..., yᵢ₊ₖ]
  2. Подгоняем полином степени m: P(x) = a₀ + a₁x + a₂x² + ... + aₘxᵐ
  3. Значение в центре окна: yᵢ_filtered = P(0) = a₀
```

**Преимущества:**
- Сохраняет форму пиков (важно для физических данных)
- Сохраняет производные (важно для анализа трендов)
- Эффективен для сигналов с высоким SNR (>20 дБ)

**Параметры:**
- `window_length`: Размер окна (должен быть нечётным, ≥ polyorder+1)
- `polyorder`: Порядок полинома (обычно 2-3)
- Автоматический выбор: `window_length = max(5, n//4)`, где n - длина сигнала

**Код:**
```python
# Автоматический выбор размера окна
window_length = min(max(5, n // 4), n if n % 2 == 1 else n - 1)
window_length = max(window_length, polyorder + 1)
if window_length % 2 == 0:
    window_length += 1  # Должно быть нечётным

# Применение фильтра
filtered = savgol_filter(curve_clean, window_length, polyorder=2, mode='nearest')
```

### 2. Гауссовский фильтр (Gaussian)

**Принцип работы:**
- Свёртка сигнала с гауссовым ядром (колоколообразная функция)
- Каждая точка заменяется взвешенным средним соседних точек
- Веса определяются гауссовым распределением

**Почему работает:**
```
yᵢ_filtered = Σⱼ wⱼ · yᵢ₊ⱼ
где wⱼ = (1/√(2πσ²)) · exp(-j²/(2σ²))
```

**Преимущества:**
- Плавное сглаживание без артефактов
- Хорошо удаляет высокочастотный шум
- Сохраняет общую форму сигнала

**Параметры:**
- `sigma`: Стандартное отклонение (ширина ядра)
  - Малый σ (0.5-1.0): слабое сглаживание, сохраняет детали
  - Большой σ (2.0-5.0): сильное сглаживание, теряет детали

**Код:**
```python
filtered = gaussian_filter1d(curve_clean, sigma=0.5, mode='nearest')
```

### 3. Фильтр Калмана (Kalman)

**Принцип работы:**
- Рекурсивный алгоритм, который оценивает "истинное" состояние системы
- Учитывает неопределённость как в измерениях, так и в модели процесса
- Использует предсказание и обновление на каждом шаге

**Почему работает:**
```
Состояние: x (истинное значение)
Ковариация: P (неопределённость)

Для каждого измерения z:
  1. Предсказание:
     x_pred = x (предполагаем, что состояние не меняется)
     P_pred = P + Q (Q - процессный шум)
  
  2. Обновление:
     K = P_pred / (P_pred + R)  # Коэффициент Калмана
     x = x_pred + K · (z - x_pred)  # Взвешенное среднее
     P = (1 - K) · P_pred
```

**Преимущества:**
- Эффективен для нестационарного шума
- Адаптируется к изменениям в данных
- Хорошо работает при наличии осцилляций

**Параметры:**
- `process_noise` (Q): Дисперсия процессного шума (0.1)
- `measurement_noise` (R): Дисперсия шума измерений (0.1)

**Код:**
```python
x = curve_clean[0]  # Начальное состояние
P = 1.0  # Начальная ковариация

for i in range(1, n):
    # Предсказание
    x_pred = x
    P_pred = P + process_noise
    
    # Обновление
    K = P_pred / (P_pred + measurement_noise)
    x = x_pred + K * (curve_clean[i] - x_pred)
    P = (1 - K) * P_pred
    filtered_values.append(x)
```

### 4. Логарифмическая фильтрация (Log-domain)

**Принцип работы:**
- Применяется, когда данные изменяются более чем на порядок (10x и более)
- Фильтрация выполняется в логарифмическом масштабе, затем возврат в линейный

**Почему работает:**
```
Если данные: [0.001, 0.01, 0.1, 1.0, 10.0]
В логарифмическом масштабе: [-3, -2, -1, 0, 1]
→ Фильтрация более равномерна
→ Возврат: 10^filtered_log
```

**Преимущества:**
- Обрабатывает данные с большим динамическим диапазоном
- Сохраняет относительные изменения
- Уменьшает влияние выбросов

**Код:**
```python
# Переход в логарифмический масштаб
log_curve = np.log10(curve_clean)

# Применение базового фильтра (SavGol, Gaussian или Kalman)
filtered_log = SignalFilters.savgol(log_curve, **kwargs)

# Возврат в линейный масштаб
filtered = 10 ** filtered_log
```

### 5. Гибридный фильтр (Hybrid)

**Принцип работы:**
- Комбинация нескольких методов для универсальной фильтрации
- Последовательное применение: SavGol → Gaussian

**Почему работает:**
```
1. SavGol: Удаляет высокочастотный шум, сохраняя форму
2. Gaussian: Дополнительное сглаживание для устранения артефактов
3. Результат: Плавный сигнал с сохранёнными основными особенностями
```

**Преимущества:**
- Универсальность: работает для разных типов сигналов
- Компенсирует недостатки отдельных методов
- Используется по умолчанию

**Код:**
```python
# 1. Savitzky-Golay для начального сглаживания
filtered = savgol_filter(filtered, window_length, polyorder=2)

# 2. Gaussian для дополнительного сглаживания
filtered = gaussian_filter1d(filtered, sigma=0.5, mode='nearest')
```

## Автоматический выбор метода

Система анализирует характеристики сигнала и выбирает оптимальный метод:

### Критерии выбора:

1. **Логарифмический масштаб** (`detect_log_scale`):
   ```python
   ratio = signal_max / signal_min
   if ratio > 10^10:  # Изменение более чем на 10 порядков
       return 'log_domain'
   ```

2. **Оценка осцилляций** (`compute_oscillation_score`):
   ```python
   # Подсчёт изменений знака второй производной
   second_deriv = gradient(gradient(signal))
   sign_changes = count_sign_changes(second_deriv)
   oscillation_score = sign_changes / len(second_deriv)
   
   if oscillation_score > 0.3:
       return 'kalman'  # Калман лучше для осцилляций
   ```

3. **SNR (Signal-to-Noise Ratio)** (`compute_snr`):
   ```python
   signal_power = mean(signal²)
   noise_power = var(signal)
   snr_db = 10 * log10(signal_power / noise_power)
   
   if snr_db > 20:
       return 'savgol'  # Высокий SNR - SavGol
   elif snr_db > 10:
       return 'gaussian'  # Средний SNR - Gaussian
   else:
       return 'hybrid'  # Низкий SNR - Hybrid
   ```

### Логика выбора:
```python
if use_log:
    return 'log_domain'
if oscillation_score > 0.3:
    return 'kalman'
if snr > 20:
    return 'savgol'
elif snr > 10:
    return 'gaussian'
else:
    return 'hybrid'  # По умолчанию
```

## Физические ограничения

После фильтрации применяются физические ограничения для обеспечения корректности кривых pD(Y):

### 1. Монотонность (`monotonic`)

**Принцип:**
- Для кривых pD(Y) типично не возрастающее поведение
- Восстанавливает монотонность, если фильтрация её нарушила

**Реализация:**
```python
# Для не возрастающей функции (справа налево)
curve_sorted = sort_by_x(curve)
curve_monotonic = maximum.accumulate(curve_sorted[::-1])[::-1]
```

**Почему работает:**
- `maximum.accumulate` гарантирует, что каждое значение ≥ предыдущего
- Обращение массива обеспечивает не возрастание

---

### 2. Ограничение кривизны (`limit_curvature`)

**Принцип:**
- Ограничивает вторую производную (кривизну) кривой
- Предотвращает резкие изгибы, нефизичные для данных ГРП

**Реализация:**
```python
# Вычисление второй производной
second_deriv = gradient(gradient(curve, x), x)

# Ограничение
second_deriv_clipped = clip(second_deriv, -max_curvature, max_curvature)

# Восстановление кривой интегрированием
first_deriv = cumsum(second_deriv_clipped)
curve_restored = cumsum(first_deriv)
```

**Почему работает:**
- Интегрирование дважды восстанавливает кривую с ограниченной кривизной
- Сохраняет начальное значение и общую форму

---

### 3. Удаление осцилляций (`remove_oscillations`)

**Принцип:**
- Обнаруживает осцилляции по изменениям знака второй производной
- Применяет сглаживание в областях с осцилляциями

**Реализация:**
```python
# Обнаружение осцилляций
second_deriv = gradient(gradient(curve))
sign_changes = diff(sign(second_deriv)) != 0
oscillation_mask = concatenate([False], sign_changes, [False])

# Сглаживание в областях с осцилляциями
if any(oscillation_mask):
    smoothed = uniform_filter1d(curve, size=window_size)
    curve[oscillation_mask] = smoothed[oscillation_mask]
```

**Почему работает:**
- Частые изменения знака второй производной указывают на осцилляции
- Локальное сглаживание устраняет осцилляции, сохраняя общую форму

---

### 4. Исправление асимптотик (`asymptotic_fix`)

**Принцип:**
- Исправляет поведение на краях кривой (ранний и поздний режимы)
- Обеспечивает плавный переход к средним значениям

**Реализация:**
```python
# Ранний режим
early_mean = mean(curve[:early_window])
for i in range(early_window):
    alpha = i / early_window
    curve[i] = alpha * curve[i] + (1 - alpha) * early_mean

# Поздний режим
late_mean = mean(curve[-late_window:])
for i in range(n - late_window, n):
    alpha = (i - (n - late_window)) / late_window
    curve[i] = alpha * curve[i] + (1 - alpha) * late_mean
```

**Почему работает:**
- Плавный переход (линейная интерполяция) предотвращает резкие скачки на краях
- Стабилизирует поведение в асимптотических режимах

## Полный процесс фильтрации

### Пример из кода (`on_ml_filter`):

```python
# 1. Подготовка данных
valid_mask = np.isfinite(Y) & np.isfinite(pD_original)
Y_clean = Y[valid_mask]
pD_clean = pD_original[valid_mask]

# 2. Автоматический выбор метода
filtered_pD = SignalFilters.denoise(pD_clean, method=None, x=Y_clean)
# Внутри denoise:
#   - select_filter_method() анализирует сигнал
#   - Выбирает оптимальный метод
#   - Применяет фильтр

# 3. Физические ограничения
filtered_pD = PhysicsConstraints.enforce_all(
    filtered_pD,
    x=Y_clean,
    monotonic=True,
    limit_curvature=True,
    remove_oscillations=True,
    asymptotic_fix=True
)

# 4. Восстановление давления
interp_func = interp1d(Y_clean, filtered_pD, kind='linear')
pD_filtered_interp = interp_func(Y)  # Интерполяция на исходную сетку
pressure_filtered = pressure_initial - pD_filtered_interp * delta_p_i
```

## Почему эти методы эффективны для данных ГРП?

### 1. **Физическая природа данных:**
- Кривые pD(Y) должны быть монотонными и гладкими
- Резкие скачки обычно являются артефактами измерений
- Фильтрация сохраняет физически корректное поведение

### 2. **Характеристики шума:**
- Шум в данных ГРП обычно высокочастотный
- Фильтры эффективно удаляют высокочастотные компоненты
- Сохраняют низкочастотные тренды (важные для анализа)

### 3. **Адаптивность:**
- Автоматический выбор метода адаптируется к характеристикам данных
- Разные методы эффективны для разных типов шума
- Гибридный подход обеспечивает универсальность

### 4. **Физические ограничения:**
- Гарантируют корректность результатов
- Предотвращают нефизичные артефакты
- Обеспечивают согласованность с теорией фильтрации

## Математическое обоснование

### Теорема Найквиста-Шеннона:
Для точного восстановления сигнала частота дискретизации должна быть ≥ 2× максимальной частоты сигнала.

**Применение:**
- Фильтры удаляют высокочастотный шум (> частота Найквиста)
- Сохраняют полезный сигнал (< частота Найквиста)

### Теория оптимальной фильтрации:
Фильтр Калмана является оптимальным (в смысле минимума среднеквадратичной ошибки) для линейных систем с гауссовым шумом.

**Применение:**
- Калман эффективен для нестационарного шума
- Адаптируется к изменениям в данных

### Полиномиальная аппроксимация:
Фильтр Савицкого-Голея основан на локальной полиномиальной аппроксимации, которая минимизирует ошибку аппроксимации.

**Применение:**
- Сохраняет форму пиков и особенности сигнала
- Эффективен для сигналов с высоким SNR
