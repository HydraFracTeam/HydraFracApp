# Анализ данных ГРП - Обновленная версия

## 🚀 Новые возможности

### ✅ Поддержка нескольких групп данных
Теперь приложение может работать с файлами, содержащими несколько групп данных с разными параметрами скважин (Skin, h, N, W, L, a/L).

### ✅ Улучшенный парсер данных
- Автоматическая группировка данных по параметрам скважины
- Поддержка CSV и Parquet файлов
- Анализ структуры данных перед загрузкой

### ✅ Профессиональный интерфейс
- Вкладки для разных типов анализа
- Выбор скважины из списка
- Расширенные возможности построения графиков

## 📊 Использование

### 1. Анализ структуры данных

Перед загрузкой данных в приложение рекомендуется проанализировать структуру файла:

```bash
python analyze_data_groups.py your_data_file.csv
```

Этот скрипт покажет:
- Количество групп данных
- Параметры каждой группы
- Рекомендации по группировке

### 2. Загрузка данных в приложение

1. Запустите приложение: `python main.py`
2. Нажмите "Загрузить файл данных"
3. Выберите CSV или Parquet файл
4. Приложение автоматически сгруппирует данные

### 3. Работа с несколькими скважинами

После загрузки:
1. В разделе "Временные ряды" выберите скважину из выпадающего списка
2. Выберите тип графика
3. Нажмите "Построить график"

## 🔧 Формат данных

### Ожидаемые колонки:
- `Skin` - фактор скин-эффекта
- `h` - толщина пласта (м)
- `N` - количество трещин
- `W` - ширина трещины (м)
- `L` - длина трещины (м)
- `a/L` - отношение a/L
- `ElemIdx` - индекс элемента
- `X`, `Y` - координаты
- `t` - время (ч)
- `P` - давление (атм)
- `dP` - изменение давления
- `Q` - дебит (м³/сут)

### Пример структуры данных:

```csv
Skin,h,N,W,L,a/L,ElemIdx,X,Y,t,P,dP,Q
0.05,10.0,5,1000.0,200.0,0.5,1,0.0,0.0,0,300.0,0,100.0
0.05,10.0,5,1000.0,200.0,0.5,2,0.0,0.0,1,298.0,-2,99.0
0.1,15.0,8,1200.0,250.0,0.6,3,0.0,0.0,0,280.0,0,90.0
0.1,15.0,8,1200.0,250.0,0.6,4,0.0,0.0,1,277.0,-3,88.0
```

## 🛠️ Устранение проблем

### Проблема: "Параметр Skin должен быть константным"

**Причина**: Старый парсер ожидал одинаковые параметры для всех строк.

**Решение**: Используйте новый парсер, который автоматически группирует данные.

### Проблема: Графики не строятся

**Возможные причины**:
1. Данные содержат NaN значения
2. Недостаточно точек для построения графика
3. Некорректные значения

**Решение**: Приложение автоматически проверяет данные и показывает информативные сообщения об ошибках.

### Проблема: Медленная работа с большими файлами

**Рекомендации**:
1. Используйте Parquet формат вместо CSV
2. Предварительно фильтруйте данные
3. Используйте скрипт анализа для понимания структуры

## 📈 Примеры использования

### Анализ режима течения

1. Загрузите данные
2. Перейдите на вкладку "Анализ ГРП"
3. Нажмите "Анализ режима течения"
4. Результаты появятся в текстовом поле

### Сопоставление с эталонными кривыми

1. Перейдите на вкладку "Эталонные кривые"
2. Нажмите "Сопоставить с данными"
3. Приложение покажет лучшее соответствие

### ML-обработка данных

1. На вкладке "Временные ряды"
2. Используйте кнопки:
   - "ML интерполяция" - заполнение пропусков
   - "ML фильтрация" - сглаживание шума
   - "Обнаружить выбросы" - поиск аномалий

## 🔬 Научные методы

### Режимы течения:
- **Билинейное течение** - наклон 1/4 на лог-лог графике
- **Линейное течение** - наклон 1/2 на лог-лог графике  
- **Псевдорадиальное течение** - наклон 0 на лог-лог графике

### ML-методы:
- **Random Forest** - для интерполяции
- **Savitzky-Golay** - для фильтрации
- **IQR, Z-score** - для обнаружения выбросов
