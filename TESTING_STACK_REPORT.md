# Отчет о стеке тестирования

## 1. Стек технологий тестирования

### Основные компоненты

#### Фреймворк тестирования
- **pytest 8.3.3** - основной фреймворк для тестирования
  - Поддержка параметризованных тестов
  - Fixtures для подготовки тестовых данных
  - Маркеры для категоризации тестов (unit, integration, slow, load)
  - Плагины для расширенной функциональности

#### Тестирование GUI
- **PySide6 (Qt 6.10.0)** - фреймворк GUI приложения
  - **QTest** - модуль для тестирования GUI компонентов
  - **QApplication** - управление событиями приложения
  - **unittest.mock (Mock, patch, MagicMock)** - мокирование компонентов

#### Тестирование производительности
- **time** - измерение времени выполнения
- **tracemalloc** - профилирование памяти Python
- **memory_profiler** (будет добавлен) - детальный анализ памяти

#### Тестирование ML-методов
- **numpy 2.3.3** - математические вычисления
- **pandas 2.3.3** - работа с данными
- **scikit-learn >=1.1.0** - ML алгоритмы
- **scipy >=1.9.0** - научные вычисления
- **matplotlib >=3.5.0** - визуализация результатов тестов

#### Визуализация данных
- **pyqtgraph 0.13.7** - быстрая визуализация в реальном времени

## 2. Реализация тестирования GUI

### 2.1. Архитектура тестирования GUI

#### Инициализация тестовой среды
```python
@pytest.fixture(scope="module")
def qapp():
    """Создает QApplication для всех тестов"""
    if not QApplication.instance():
        app = QApplication(sys.argv)
    else:
        app = QApplication.instance()
    yield app
```

#### Тестовый режим приложения
- Флаг `test_mode=True` отключает QMessageBox для автоматизации
- Синтетические данные для тестирования без реальных файлов
- Изоляция тестов через fixtures

### 2.2. Категории GUI тестов

#### Интеграционные тесты (`test_gui_integration.py`)
- **Инициализация приложения**: проверка создания всех компонентов
- **Заполнение элементов управления**: combo boxes, buttons
- **Загрузка данных**: тестирование WellTimeSeries
- **Диалоги**: мокирование QFileDialog
- **Подключение сигналов**: проверка связей кнопок и обработчиков

#### Функциональные тесты
- **Построение графиков**: различные типы визуализаций
- **Обработка данных**: интерполяция, фильтрация, обнаружение выбросов
- **Анализ режимов течения**: билинейное, линейное, псевдорадиальное
- **Экспорт данных**: сохранение результатов

#### Тесты обработки ошибок
- **Построение без данных**: graceful handling
- **Некорректные данные**: NaN, Inf, -Inf
- **Пустые файлы**: обработка edge cases

#### Нагрузочные тесты (`test_gui_load.py`)
- **1000 кликов по кнопке "Построить график"**:
  - Проверка стабильности
  - Отсутствие утечек памяти
  - Проверка времени выполнения
  
- **100 кликов по интерполяции**:
  - Отсутствие зависаний
  - Идемпотентность операций
  - Проверка отзывчивости GUI

- **Быстрые последовательные клики**:
  - Проверка на race conditions
  - Отзывчивость < 100ms между операциями

### 2.3. Измерение производительности GUI

#### Время отклика кнопок
```python
def measure_button_response_time(app, button_method):
    start = time.perf_counter()
    button_method()
    QApplication.instance().processEvents()
    elapsed = time.perf_counter() - start
    return elapsed * 1000  # в миллисекундах
```

#### Профилирование памяти
```python
import tracemalloc

tracemalloc.start()
snapshot1 = tracemalloc.take_snapshot()

# Выполнение операций

snapshot2 = tracemalloc.take_snapshot()
top_stats = snapshot2.compare_to(snapshot1, 'lineno')
total_memory = sum(stat.size_diff for stat in top_stats)
```

## 4. Конфигурация pytest

```ini
[tool:pytest]
testpaths = tests
python_files = test_*.py
python_classes = Test*
python_functions = test_*
addopts = -v --tb=short
markers =
    unit: Unit tests
    integration: Integration tests
    slow: Slow running tests
    load: Load tests
    performance: Performance tests
    memory: Memory tests
    longrun: Long running stability tests
```

## 5. Запуск тестов

### Все тесты
```bash
pytest tests/ -v
```

### Только быстрые тесты
```bash
pytest tests/ -v -m "not slow and not load and not longrun"
```

### Тесты производительности
```bash
pytest tests/ -v -m performance
```

### Нагрузочные тесты
```bash
pytest tests/ -v -m load
```

### Долгие тесты стабильности
```bash
pytest tests/ -v -m longrun
```

### Покрытие кода
```bash
pytest tests/ --cov=. --cov-report=html
```
