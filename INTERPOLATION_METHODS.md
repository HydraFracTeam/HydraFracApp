# Методы интерполяции для ГРП данных

## Обзор

В проекте реализованы различные методы интерполяции, специально адаптированные для обработки данных гидроразрыва пласта (ГРП). Каждый метод имеет свои преимущества и области применения.

## Доступные методы

### 1. Классические методы

#### Линейная интерполяция
- **Описание**: Простая линейная интерполяция между соседними точками
- **Применение**: Быстрая обработка, когда точность не критична
- **Преимущества**: Быстрота, простота
- **Недостатки**: Может создавать резкие переходы

#### Сплайн-интерполяция
- **Описание**: Кубические сплайны для гладкой интерполяции
- **Применение**: Когда нужна гладкая кривая
- **Преимущества**: Гладкость, точность
- **Недостатки**: Может создавать осцилляции

### 2. Машинное обучение

#### Random Forest интерполяция
- **Описание**: Использует ансамбль деревьев решений
- **Применение**: Сложные нелинейные зависимости
- **Преимущества**: Устойчивость к выбросам, хорошая точность
- **Недостатки**: Может переобучаться на малых данных

#### Полиномиальная регрессия
- **Описание**: Полиномиальные признаки с линейной регрессией
- **Применение**: Полиномиальные зависимости
- **Преимущества**: Простота интерпретации
- **Недостатки**: Может переобучаться

#### Ridge регрессия
- **Описание**: Линейная регрессия с L2 регуляризацией
- **Применение**: Когда нужна стабильность
- **Преимущества**: Предотвращает переобучение
- **Недостатки**: Может быть слишком консервативной

### 3. Продвинутые методы

#### Кригинг-интерполяция
- **Описание**: Геостатистический метод с учетом пространственной корреляции
- **Применение**: Пространственные данные, когда важна корреляция
- **Преимущества**: Учитывает пространственную структуру
- **Недостатки**: Требует много данных для обучения

#### Радиальные базисные функции (RBF)
- **Описание**: Интерполяция с помощью радиальных функций
- **Применение**: Неравномерно распределенные данные
- **Преимущества**: Гибкость, хорошая точность
- **Недостатки**: Может быть нестабильной

#### Гауссовские процессы (GP)
- **Описание**: Байесовский подход с оценкой неопределенности
- **Применение**: Когда важна оценка неопределенности
- **Преимущества**: Оценка неопределенности, адаптивность
- **Недостатки**: Вычислительная сложность

### 4. Специализированные методы

#### Физически ограниченная интерполяция
- **Описание**: Интерполяция с учетом физических ограничений ГРП
- **Применение**: Данные давления и дебита
- **Преимущества**: Соответствие физическим законам
- **Недостатки**: Может быть слишком консервативной

#### Адаптивная интерполяция
- **Описание**: Автоматический выбор лучшего метода
- **Применение**: Когда не знаете, какой метод использовать
- **Преимущества**: Автоматический выбор, хорошая точность
- **Недостатки**: Дополнительные вычисления

## Рекомендации по использованию

### Для данных давления:
1. **Физически ограниченная интерполяция** - лучший выбор
2. **GP с неопределенностью** - если нужна оценка точности
3. **Адаптивная интерполяция** - универсальный выбор

### Для данных дебита:
1. **RBF интерполяция** - для сложных зависимостей
2. **ML (Random Forest)** - для больших объемов данных
3. **Кригинг** - если есть пространственная корреляция

### Для общих случаев:
1. **Адаптивная интерполяция** - автоматический выбор
2. **GP** - если нужна оценка неопределенности
3. **Сплайн** - для гладких кривых

## Примеры использования

### Базовое использование:
```python
from helpers.ml_methods import apply_adaptive_interpolation

# Автоматический выбор лучшего метода
interpolated = apply_adaptive_interpolation(time_series, values_series)
```

### С оценкой неопределенности:
```python
from helpers.ml_methods import apply_gp_interpolation

# GP с оценкой неопределенности
mean, std = apply_gp_interpolation(time_series, values_series, return_std=True)
```

### Физически ограниченная:
```python
from helpers.ml_methods import apply_physics_constrained_interpolation

# Для данных давления
interpolated = apply_physics_constrained_interpolation(
    time_series, pressure_series, 'pressure'
)
```

## Параметры настройки

### Кригинг:
- `variogram_model`: 'spherical', 'exponential', 'linear'
- `nugget`: уровень шума

### RBF:
- `function`: 'multiquadric', 'gaussian', 'linear'
- `smoothing`: параметр сглаживания

### GP:
- `kernel`: 'rbf', 'matern'
- `alpha`: уровень шума

### Физически ограниченная:
- `max_pressure_gradient`: максимальный градиент давления
- `min_flow_rate`: минимальный дебит
- `max_flow_rate`: максимальный дебит

## Заключение

Выбор метода интерполяции зависит от:
- Типа данных (давление, дебит, время)
- Требований к точности
- Наличия физических ограничений
- Объема данных
- Необходимости оценки неопределенности

Для большинства случаев ГРП данных рекомендуется использовать **адаптивную интерполяцию** или **физически ограниченную интерполяцию**.
