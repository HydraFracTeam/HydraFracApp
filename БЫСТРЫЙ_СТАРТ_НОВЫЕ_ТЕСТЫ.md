# 🚀 Быстрый старт - Новые тесты с диалогами

## Что нового?

Теперь есть **2 способа** тестирования GUI:

### 1. Быстрый (test_mode) ⚡
```bash
pytest tests/test_comprehensive_performance.py -v
```
- Диалоги НЕ показываются
- Очень быстро (~5-8 минут)
- Для разработки и CI/CD

### 2. Реалистичный (автозакрытие) 🎭
```bash
pytest tests/test_gui_with_dialogs.py -v -s
```
- Диалоги показываются и автоматически закрываются
- Медленнее (~10-15 минут)
- Для интеграционного тестирования

---

## Команды

### Запуск быстрых тестов
```bash
# Все быстрые тесты
pytest tests/test_comprehensive_performance.py -v -m "not longrun"

# Только время отклика
pytest tests/test_comprehensive_performance.py::TestGUIResponseTime -v
```

### Запуск реалистичных тестов
```bash
# Все тесты с диалогами
pytest tests/test_gui_with_dialogs.py -v -s

# Без нагрузочных
pytest tests/test_gui_with_dialogs.py -v -s -m "not load"

# Только один тест
pytest tests/test_gui_with_dialogs.py::TestGUIWithRealDialogs::test_plot_button_with_dialog_auto_close -v -s
```

### Запуск обоих типов
```bash
# Сначала быстрые
pytest tests/test_comprehensive_performance.py -v -m "not longrun"

# Потом реалистичные
pytest tests/test_gui_with_dialogs.py -v -s -m "not load"
```

## Что тестируется?

### Быстрые тесты (23 теста)
- ✅ Время отклика GUI < 500ms
- ✅ Failure rate < 1%
- ✅ Линейный рост памяти
- ✅ Загрузка данных < 5 сек/100K
- ✅ Точность ML > 95%
- ✅ Деградация < 15%

### Реалистичные тесты (10 тестов)
- ✅ Время отклика с диалогами < 1000ms
- ✅ Автозакрытие диалогов работает
- ✅ 100 операций без сбоев
- ✅ Стабильность механизма закрытия

---

## Критерии

| Тип теста | Время отклика | Включает |
|-----------|---------------|----------|
| Быстрый ⚡ | < 500ms | Только логика |
| Реалистичный 🎭 | < 1000ms | Логика + диалог |

## Настройка окружения

### Windows PowerShell
```powershell
$env:QT_QPA_PLATFORM="offscreen"
```

### Windows CMD
```cmd
set QT_QPA_PLATFORM=offscreen
```

### Linux / Mac
```bash
export QT_QPA_PLATFORM=offscreen
```

## Troubleshooting

### Диалоги не закрываются?
```bash
# Увеличьте интервал в коде:
timer = setup_dialog_auto_closer(interval_ms=100)  # Было 50
```

### Тесты зависают?
```bash
# Запустите с выводом
pytest tests/test_gui_with_dialogs.py -vv -s
```
