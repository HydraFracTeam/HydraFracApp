# Инструкция по запуску тестов

## ⚡ Быстрый запуск

### Все быстрые тесты (< 5 минут)
```bash
pytest tests/test_comprehensive_performance.py -v -m "not longrun"
```

### Конкретные группы

#### 1. Время отклика GUI < 500ms
```bash
pytest tests/test_comprehensive_performance.py::TestGUIResponseTime -v -s
```

#### 2. Failure rate < 1%  
```bash
pytest tests/test_comprehensive_performance.py::TestFailureRate -v -s
```

#### 3. Потребление памяти (линейный рост)
```bash
pytest tests/test_comprehensive_performance.py::TestMemoryConsumption -v -s
```

#### 4. Загрузка данных < 5 сек/100K
```bash
pytest tests/test_comprehensive_performance.py::TestDataLoadingPerformance -v
```

#### 5. Точность ML > 95%
```bash
pytest tests/test_comprehensive_performance.py::TestMLAccuracy -v
```

#### 6. Долгая стабильность (⚠️ 10-20 минут!)
```bash
pytest tests/test_comprehensive_performance.py::TestLongTermStability -v -s
```

## 📊 Автоматический запуск с отчетом

```bash
python run_comprehensive_tests.py
```

Этот скрипт:
- Запускает все группы тестов последовательно
- Спрашивает перед запуском long-running тестов
- Генерирует отчет в `test_report.txt`

## 🔧 Настройка окружения (для Windows)

```powershell
# В PowerShell
$env:QT_QPA_PLATFORM="offscreen"
pytest tests/test_comprehensive_performance.py -v
```

```cmd
# В CMD
set QT_QPA_PLATFORM=offscreen
pytest tests/test_comprehensive_performance.py -v
```

## 📈 С покрытием кода

```bash
pytest tests/test_comprehensive_performance.py --cov=. --cov-report=html --cov-report=term
```

Отчет будет в `htmlcov/index.html`

## 🐛 Отладка

### Детальный вывод
```bash
pytest tests/test_comprehensive_performance.py -vv -s
```

### Остановка на первой ошибке
```bash
pytest tests/test_comprehensive_performance.py -x -v
```

### Только проваленные тесты
```bash
pytest --lf tests/test_comprehensive_performance.py -v
```

### Конкретный тест
```bash
pytest tests/test_comprehensive_performance.py::TestGUIResponseTime::test_plot_button_response_time -v -s
```

## ⏱️ Ожидаемое время выполнения

| Группа тестов | Время | Маркер |
|---------------|-------|--------|
| GUI Response Time | ~2 минуты | `performance` |
| Failure Rate | ~3-5 минут | `load` |
| Memory Consumption | ~1 минута | `memory` |
| Data Loading | ~30 секунд | `performance` |
| ML Accuracy | ~10 секунд | `unit` |
| Long-term Stability | **10-20 минут** | `longrun` |

**Итого без longrun:** ~6-8 минут  
**Итого с longrun:** ~16-28 минут
