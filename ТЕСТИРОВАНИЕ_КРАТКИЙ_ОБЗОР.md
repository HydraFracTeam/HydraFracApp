# Тестирование - Краткий обзор

## 🎯 Цель

Комплексная система тестирования приложения для анализа гидравлического разрыва пласта (ГРП), покрывающая все ключевые метрики качества.

## ✅ Реализованные требования

| № | Требование | Критерий | Статус |
|---|------------|----------|--------|
| 1 | Время отклика GUI | < 500ms (кроме загрузки) | ✅ |
| 2 | Failure rate | < 1% | ✅ |
| 3 | Потребление памяти | Линейный рост O(n) | ✅ |
| 4 | Загрузка данных | < 5 сек/100K строк | ✅ |
| 5 | Точность ML | > 95% | ✅ |
| 6 | Стабильность | Деградация < 15% | ✅ |

## 🐛 Troubleshooting

### Проблема: GUI тесты не запускаются
**Решение:** Установите переменную окружения `QT_QPA_PLATFORM=offscreen`

### Проблема: Тесты зависают
**Решение:** Запустите с флагом `-s` для вывода прогресса

### Проблема: Недостаточно памяти
**Решение:** Уменьшите количество итераций в долгих тестах (временно)

```python
@pytest.mark.performance
def test_plot_button_response_time(self, app_with_data):
    times = []
    for _ in range(20):
        start = time.perf_counter()
        app.on_plot_dimensionless_selected()
        QApplication.instance().processEvents()
        times.append((time.perf_counter() - start) * 1000)
    
    avg_time = np.mean(times)
    assert avg_time < 500  # критерий
```
