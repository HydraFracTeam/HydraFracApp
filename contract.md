                                                                                                                                                                                                                                                                                                                                                          
# Контракт для агента

**Задача: разделение аппроксимации безразмерных X–Y кривых на два класса по степени пологости и обучение специализированных моделей**

## 1. Общая цель

Повысить точность аппроксимации и экстраполяции безразмерных X–Y кривых за счёт:

* автоматического разделения кривых на **пологие** и **крутые**;
* обучения **раздельных моделей аппроксимации** для каждого типа;
* использования простой классификации формы кривой вместо усредняющей универсальной модели.

---

## 2. Входные данные

Для каждого сценария (скважины):

* безразмерная кривая в виде массивов
  `X = {X_i}`, `Y = {Y_i}`
* (P, Q используются только для построения X–Y и в этой задаче напрямую не участвуют)

---

## 3. Модуль оценки пологости (обязательная реализация)

### 3.1. Определение метрики пологости

Для каждой X–Y кривой вычислить **скалярную метрику пологости**, например (одну или комбинацию):

* средний наклон в логарифмических координатах
  [
  k = \text{median}\left(\frac{d \log Y}{d \log X}\right)
  ]
* или аппроксимация кривой в log–log пространстве и извлечение коэффициента наклона;
* или интегральная кривизна / отношение диапазонов:
  [
  S = \frac{\log(Y_{max}/Y_{min})}{\log(X_{max}/X_{min})}
  ]

(конкретная формула выбирается агентом, но **результат — один скаляр на кривую**).

---

### 3.2. Глобальное разделение по медиане

* Для **всего обучающего массива кривых**:

  * вычислить метрику пологости для каждой кривой;
  * вычислить **медиану** по всему массиву.

### 3.3. Присвоение классов

Для каждой кривой:

* если `politeness_metric ≤ median` → **класс 0 (пологая)**
* если `politeness_metric > median` → **класс 1 (крутая / экспоненциальная)**

Класс сохраняется:

* для обучения классификатора;
* для обучения специализированных аппроксиматоров;
* при необходимости — для анализа в GUI.

---

## 4. Обучение классификатора формы кривой

### 4.1. Вход классификатора

Признаки, вычисляемые **из X–Y кривой**:

* метрика пологости;
* дисперсия наклона;
* отношение диапазонов `ΔlogY / ΔlogX`;
* при необходимости — простые статистики формы.

⚠️ **Классификатор НЕ использует эталон**, работает только по форме кривой.

### 4.2. Выход классификатора

Бинарный класс:

* `0` — пологая кривая
* `1` — крутая кривая

Допускается:

* простой ML (логрег, SVM, дерево);
* либо rule-based логика (если метрика устойчива).

---

## 5. Обучение аппроксиматоров

### 5.1. Раздельные модели

Обучить **две независимые модели аппроксимации X–Y**:

* модель для класса 0 (пологие);
* модель для класса 1 (крутые).

Каждая модель обучается **только на кривых своего класса**.

### 5.2. Ограничения

Физические штрафы и ограничения применяются **ТОЛЬКО на этапе аппроксимации**, а не классификации:

* монотонность;
* отсутствие резких скачков;
* ограничение на локальную кривизну;
* контроль взрывного роста/затухания.

---

## 6. Использование в предсказании (онлайн)

Пайплайн:

1. `P,Q → X,Y`
2. вычисление признаков формы X–Y
3. классификация типа кривой (0 / 1)
4. выбор соответствующей аппроксимационной модели
5. аппроксимация / экстраполяция X–Y с физическими ограничениями

---

## 7. Ожидаемый эффект

* устранение усреднения между пологими и крутыми кривыми;
* точность на случайных 10 кривых >50%;
* рост точности аппроксимации по сравнению с одной универсальной моделью;
* снижение ошибок в диапазоне ранних режимов;
* стабильность экстраполяции без эталона.
